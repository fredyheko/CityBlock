# Генератор лицензионных ключей «Заявки PM»

`generator.html` открывается двойным щелчком в **Chrome или Edge** на компьютере.
Интернет не нужен, файл ничего никуда не отправляет.

## Как выдать ключ
1. Человек ставит «Заявки PM» и видит экран «Нужен лицензионный ключ» с **кодом телефона**
   (например `K7QM-3XRA`). Он присылает вам этот код.
2. Откройте `generator.html`, вставьте **ключ владельца** (`PMOWNER-…`) —
   можно отметить «Запомнить на этом компьютере».
3. Введите код телефона, имя, срок → **Создать ключ** → «Копировать с текстом» → отправьте человеку.
4. Он вставляет ключ в приложение → «Активировать».

Ключ работает **только на телефоне с этим кодом** и **до указанной даты**.
Код меняется после сброса телефона к заводским настройкам — тогда нужен новый ключ.

## Ключ владельца
Секретный ключ `PMOWNER-…` **не хранится в репозитории и в приложении**. Кто им владеет —
может выдавать ключи. Храните его надёжно; если он потерян, придётся выпустить новую
версию приложения с новой парой ключей (старые лицензии перестанут работать).

В приложении «Я владелец» (внизу экрана лицензии) + ключ владельца = работа без лицензии.
