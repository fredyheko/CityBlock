# «Заявки PM» — Android-приложение

Само входит на https://pm1.starnet.md под вашим логином, раз в N минут проверяет
список **Unassigned** (или Inbox) и показывает **уведомление на телефоне** со звуком
о каждой новой заявке. Уведомления можно дублировать в Telegram.

## Установка
1. Скачайте `zayavki-pm.apk` на телефон и откройте его.
2. Если Android спросит, разрешите установку из этого источника.
3. Откройте «Заявки PM», введите логин и пароль от ProcessMaker и нажмите **Сохранить и запустить**.
4. Разрешите уведомления и работу без ограничений батареи. Иначе Android
   может усыплять проверку.

В уведомлении о заявке есть адрес, **телефон клиента** (с кнопкой «Позвонить»), **описание
работ** и последние заметки (Case Notes). Телефон и описание приложение ищет в заметках и
сводке заявки (то, что открывают значки «Sum…» и «Case Notes» на сайте).

Если телефон или описание не появляются, нажмите **«Диагностика»**, затем «Копировать», и
пришлите текст разработчику. В нём видно, что сайт отдаёт по заявке.

В шторке появится постоянное уведомление «Мониторинг заявок включён» со временем последней
проверки и числом заявок. Нажатие на уведомление о заявке открывает сайт прямо в приложении,
вход уже выполнен.

## Настройки
| | |
|---|---|
| Что проверять | Unassigned или Inbox |
| Каждые N минут | по умолчанию 1 |
| Не давать телефону засыпать | включено: уведомления приходят вовремя, но расход батареи выше. Выключено: экономнее, но в глубоком сне Android может задерживать проверку примерно до 10 минут |
| Telegram | токен бота от @BotFather и chat id, если уведомления нужны ещё и в Telegram |

На Xiaomi, Huawei и Samsung дополнительно включите для приложения **автозапуск** и отключите
оптимизацию батареи в настройках телефона. Эти прошивки агрессивно закрывают фоновые приложения.

## Как устроено
- Вход идёт через невидимый встроенный браузер (WebView): открывается настоящая страница входа,
  вписываются логин и пароль, нажимается кнопка. Это то же самое, что войти вручную.
- Список заявок берётся тем же запросом, что и на сайте: `cases/proxyCasesList?action=unassigned`.
- Если сессия истекла, приложение входит заново само. После 3 ошибок подряд оно показывает
  уведомление об ошибке.
- Пароль хранится только на телефоне, в закрытых настройках приложения.

## Сборка
Нужны JDK 17+ и Android SDK (`platforms;android-35`, `build-tools;35.0.0`). Gradle не нужен:
```
ANDROID_HOME=/путь/к/sdk ./build.sh      # → build/zayavki-pm.apk
```
Если `release.keystore` (ключ подписи) нет, `build.sh` создаст новый. Ключ в git не хранится.
APK, подписанный другим ключом, не встанет поверх старой версии: её сначала нужно удалить.

Тесты логики запускаются на обычной JVM, нужен `json.jar` из org.json:
```
javac -cp json.jar -d out src/md/cityblock/zayavki/{PmCore,LoginJs}.java test/CoreTest.java
java -cp json.jar:out md.cityblock.zayavki.CoreTest
```
