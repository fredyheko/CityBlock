# ProcessMaker для iPhone

То же, что Android-версия: заявки Unassigned / Inbox / Draft карточками, экран заявки
с кнопкой «Позвонить», «Взять заявку», формы PM на весь экран, «+» (New case).

**Чего нет на iPhone:** фоновой проверки и уведомлений — iOS не даёт приложениям проверять
сайт каждую минуту. Уведомления о новых заявках приходят в **Telegram** (от Android-телефона
или компьютера с монитором). Пока приложение открыто, список обновляется раз в минуту
и по жесту «потянуть вниз».

## Где взять файл

GitHub → репозиторий → **Releases** → **ios-latest** → `ProcessMaker.ipa`.
Файл собирается автоматически при каждом изменении папки `ios-app/`.

## Установка (бесплатно, с компьютера)

Нужны: компьютер с Windows или Mac, кабель для iPhone и Apple ID (тот же, что на телефоне,
или любой другой).

1. **Компьютер:** установите **iTunes** (Windows: с сайта apple.com, *не* из Microsoft Store)
   и **Sideloadly** — https://sideloadly.io.
2. Подключите iPhone кабелем, на телефоне нажмите «Доверять этому компьютеру».
3. Откройте Sideloadly:
   - перетащите `ProcessMaker.ipa` в окно;
   - в поле **Apple account** введите свой Apple ID;
   - нажмите **Start**, введите пароль Apple ID (и код подтверждения, если спросит).
4. **iPhone:** Настройки → Основные → **VPN и управление устройством** → ваш Apple ID →
   **Доверять**.
5. Только для iOS 16 и новее: Настройки → Конфиденциальность и безопасность →
   **Режим разработчика** → включить, телефон перезагрузится → подтвердить «Включить».
6. Откройте ProcessMaker → ⚙️ → логин и пароль → «Сохранить».

### Раз в 7 дней

С бесплатным Apple ID приложение работает **7 дней**, потом перестаёт открываться.
Чтобы продлить — снова подключите iPhone и нажмите Start в Sideloadly с тем же файлом
(настройки сохранятся). Sideloadly умеет делать это сам по Wi-Fi, если компьютер включён
(галочка «Automatically refresh»).

С платным аккаунтом разработчика Apple (99 $ в год) приложение работает год.

## VPN

В приложении WireGuard: откройте туннель → **Изменить** → **Включать по запросу**:
отметьте «Сотовая связь», снимите «Wi-Fi». VPN будет сам включаться на мобильном интернете
и выключаться на Wi-Fi.

## Сборка вручную (на Mac)

```
brew install xcodegen
cd ios-app && xcodegen generate
open ProcessMakerApp.xcodeproj
```
